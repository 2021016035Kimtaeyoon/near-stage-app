# 브랜드 아이콘

`src/components/shell/logoGeometry.ts` 의 좌표를 그대로 import 해서 렌더링했습니다.
로고 지오메트리는 확정 자산이라 수정하지 않았고, 이 이미지들은 그 자산의 렌더 결과입니다.

| 파일 | 용도 |
| --- | --- |
| `icon-gold-*.png` | 밝은 금색 배경 + 먹색 로고. 작은 크기에서 잘 보여 앱 아이콘에 적합합니다. |
| `icon-dark-*.png` | 어두운 무대 배경 + 흰색/금색 로고. 브랜드 톤에 가깝습니다. |

크기는 1024 / 512 / 256 / 128 네 가지입니다.
카카오 개발자 콘솔 앱 아이콘은 최소 128x128 을 요구합니다.

## 다시 만들려면

`public/_icon-gen.html` 를 만들어 logoGeometry.ts 를 import 한 뒤 헤드리스 크롬으로
`--window-size=1024,1024 --screenshot` 하면 됩니다. 생성용 파일은 저장소에 남기지 않았습니다.
